=====================================================================
  IDS/IPS - Guia rapida (captura EN VIVO)
=====================================================================

REQUISITO: Python 3.
Captura en vivo -> sudo (Linux)  /  administrador + Npcap (Windows).

---------------------------------------------------------------------
  LINUX (Kali / Ubuntu / Debian)
---------------------------------------------------------------------
  Requisitos (una vez):
     sudo apt update && sudo apt install -y python3-venv python3-pip

  1) Arrancar el IDS EN VIVO (instala todo la primera vez):
     bash run_live.sh

  2) (Opcional) El panel web, en OTRA terminal:
     sudo ./venv/bin/python3 -m src.web.app
     -> abre http://127.0.0.1:5000

---------------------------------------------------------------------
  WINDOWS
---------------------------------------------------------------------
  Usa el ejecutable: instala Npcap (https://npcap.com) y doble clic en
  ids.exe (pedira permisos de administrador). Ver LEEME_EXE.txt.

---------------------------------------------------------------------
  QUE VAS A VER
---------------------------------------------------------------------
  Los 4 modulos activos: Listas Blancas, Monitoreo de Sitios,
  IPs Peligrosas (Threat Intel) y Forense (Whois/AbuseIPDB).
  Las alertas aparecen en consola y en el panel web; y por correo si
  configuras el SMTP.

  CORREO (opcional): copia .env.example a .env y pon tus datos SMTP,
  o configuralo desde el panel (vista "Correo").
=====================================================================
